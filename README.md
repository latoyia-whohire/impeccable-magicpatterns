# Impeccable (Magic Patterns edition)

A slimmed-down copy of the [Impeccable](https://github.com/pbakaus/impeccable) design skill by Paul Bakaus, packaged so it fits within Magic Patterns' per-file size limit.

The `scripts/` folder (helper program and its large data files) is removed, since Magic Patterns can't run it. `SKILL.md` and all `reference/` guides are unchanged from Impeccable v4.4.0.

Install in Magic Patterns (Settings → Skills → Install Skill):

```
npx skills add latoyia-whohire/impeccable-magicpatterns --skill impeccable
```
